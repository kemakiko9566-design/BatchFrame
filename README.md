# BatchFrame

本地照片批量排版工具的 Web 验证版。支持白边、真实相纸比例与印相尺寸参考，将 JPEG、PNG、WebP 照片完整适配到发布画布，生成 JPEG 图片。

## 启动

需要 Node.js 22.12+ 和 npm。在项目根目录运行：

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。开发服务器默认只监听本机。

## 使用

1. 选择平台和画布比例，再添加照片；也可点击「试用示例」。
2. 选择白边、相纸或摄影师参考，调整画布背景色和比例。切换「照片 / 平台示意」检查成品和发布布局。
3. 点击「保存或分享」生成 JPEG，在结果页调用系统分享、逐张下载或打开图片保存。

点击「保存或分享」生成图片后，在结果页交付。浏览器支持文件分享时可打开系统分享面板；否则逐张下载或打开图片使用系统保存操作。不生成 ZIP，不直接发布到社媒，也不保证浏览器能直接写入相册。系统分享结束不代表保存成功。

## 样式与限制

- 成品宽约 1080px，宽高按比例整数倍生成；不保留原图像素尺寸。
- 白边提供可视化档位和自定义增减。
- 相纸支持 instax Mini、Square、Wide，外形与成像区比例固定，外层画布独立设置；上下成像区位置为近似，屏幕显示不是实物等大。
- 摄影师参考目前只有 Walker Evans 的单件馆藏印相尺寸，居中布局由尺寸推算，详情附来源，不代表摄影师统一边框标准。
- 系统文件分享需要浏览器支持及安全上下文。手机相册保存、方向处理和大批量性能仍需在 iOS Safari、Android Chrome 实测。

预览与成品使用相同布局计算；正式输出重新读取原图。社媒外框只参与界面预览，不进入成品。原图和结果保留在当前会话，不持久保存，不包含离线缓存。输出顺序生成以限制同时解码数量，大图与大批量的内存表现仍需设备实测。

## 开发

```sh
npm test
npm run build
```

`npm test` 检查布局几何，`npm run build` 检查类型并生成 `dist/`。这两项不代替浏览器视觉验收或手机交付实测。

- `technical-spike/`：页面、交互、图片生成和布局测试。
- `packages/core/`：预览与成品共用的布局计算。
- `packages/renderer-canvas/`：Canvas 绘制。
- `public/demo/`：本地示例图片。

手机交付与界面验收步骤见 [技术验证说明](technical-spike/README.md)，业务与数据流见 [手机流程与架构](docs/mobile-flow-architecture.md)，选定视觉参考见 [设计图](docs/design/mobile-ui-selected.png)。[PRD](PRD.md) 包含长期规划，现有功能以本 README 为准。
